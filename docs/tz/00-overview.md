# ШторБаза v2.0 — Заказы и Производство

## Обзор и содержание

Это ТЗ разбито на отдельные файлы по модулям, чтобы с каждым можно было работать независимо, не перечитывая всё целиком.

| Файл | Что внутри |
|---|---|
| [01-orders-payments.md](./01-orders-payments.md) | Модуль «Заказы» + модуль «Оплата» |
| [02-production.md](./02-production.md) | Производственный цикл: очередь, приём заказа, «Готово» |
| [03-products-attributes.md](./03-products-attributes.md) | Товары: типы, динамические атрибуты, вариации |
| [04-notifications.md](./04-notifications.md) | Уведомления менеджеру и сотрудникам |
| [05-ui-tablet.md](./05-ui-tablet.md) | UI/UX-требования для планшета |
| [06-gap-analysis.md](./06-gap-analysis.md) | Что уже есть в коде ShtorBase, что меняется, что новое |
| [07-supabase-changes.md](./07-supabase-changes.md) | **Всё, что нужно прогнать в Supabase** — SQL по шагам |

> Старая версия одним файлом: `docs/TZ-orders-production.md` (оставлена для истории, актуальную работу вести по файлам в этой папке).

## Контекст

Это дополнение к `docs/TZ.md` (v1.0 — каталог и остатки). Каталог, аутентификация, роли и аудит уже реализованы. Здесь описан второй слой: приём заказа менеджером → производство сотрудниками → оплата → уведомления.

## Сквозной бизнес-процесс

```
Клиент (WhatsApp/звонок)
        │
        ▼
┌───────────────────┐   создаёт заказ    ┌────────────────────┐
│      Менеджер      │ ─────────────────▶ │  Заказ: «Новый»    │
│  вводит параметры,  │                    │  видим всем        │
│  выбирает оплату    │                    │  сотрудникам       │
└───────────────────┘                    └──────────┬─────────┘
                                                      │ ✅ «Принять заказ»
                                                      ▼
                                          ┌────────────────────┐
                                          │  Заказ: «В работе»  │
                                          │  назначен сотруднику│
                                          └──────────┬─────────┘
                                                      │ ✅ «Готово»
                                                      ▼
                                          ┌────────────────────┐
                                          │  Заказ: «Готов»     │──── 🔔 уведомление менеджеру
                                          └──────────┬─────────┘
                                                      │ менеджер связывается с клиентом
                                                      ▼
                                          ┌────────────────────┐
                                          │ «Выдан» / «Отменён» │
                                          └────────────────────┘
```
